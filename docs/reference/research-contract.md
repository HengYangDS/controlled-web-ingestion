# Research Contract

## Primary object

Controlled Web Ingestion belongs to Research's **Knowledge Systems** domain. It
is a controlled admission capability for bounded acquisition from approved
public-web targets—not a standing scraper or general content-delivery service.

## Authority boundary

The tracked policy, authorized workloads, schema, code, tests and body-redacted
evidence are authoritative. Runtime containers, temporary credentials, raw
responses, fetched bodies and local caches remain outside Git and cannot become
durable evidence.

## Portfolio interface

The sole Knowledge Systems transfer is a policy-validated, body-redacted staged
receipt for independent manual acceptance. This repository has no authority to
start Project N.O.M.A.D. services, change RAG policy, or alter any host runtime.
